FindDaisy 隐私政策

更新日期：2026年10月20日

生效日期：2026年10月20日

欢迎您使用 FindDaisy（以下简称“本游戏”）。

本游戏是一款在 Windows 系统上单机运行的叙事探索游戏。本游戏不设立账号体系，不提供联网功能，不接入任何第三方广告、统计、支付或数据分析服务。因此在您下载、安装、启动和游玩本游戏的全过程中，我们不收集、不上传、不存储您的个人信息，也不向任何第三方提供您的个人信息。

一、我们如何收集和使用您的个人信息

（一）我们不收集您的个人信息

本游戏不提供账号注册、登录、内购、充值、广告或任何形式的付费功能，也不需要绑定手机号码、电子邮箱或第三方账号。在您使用本游戏的过程中，我们不会收集下列信息：

1. 您的姓名、身份证件号码、手机号码、电子邮箱等身份信息；

2. 您的设备标识符、设备型号、操作系统版本、网络地址等设备信息；

3. 您的位置信息、通讯录、短信、相册、剪贴板等设备内容；

4. 您的游戏行为统计数据、崩溃日志或使用习惯记录。

本游戏不申请摄像头、麦克风、定位、通讯录、屏幕录制等任何系统权限，也不会在您不知情的情况下读取上述权限所对应的信息。

（二）本游戏在您设备本地保存的数据

为了让您下次打开时能够继续上次的进度，本游戏会在您本人的设备上写入少量本地数据，仅包含以下两类：

1. 游戏进度：当前会话编号、已完成的操作、已获得的使用权限、窗口位置与阅读位置等；

2. 使用偏好：界面语言选择、音乐音量设置。

上述数据仅保存在您本人的计算机本地，具体位置为 Windows 系统当前用户的应用数据目录下的 FindDaisy2.Neutralino 文件夹。这些数据不会上传至任何服务器，不会回传给我们，不会与任何在线服务同步，我们无法访问、查看或读取其中的内容。

（三）我们不将您的信息用于任何其他用途

由于本游戏不收集个人信息，因此不存在将个人信息用于广告推送、用户画像、个性化推荐、数据交易或其他任何用途的情形。本游戏运行期间不发起任何对外网络请求。

二、我们如何保存您的个人信息

（一）保存位置

本游戏不设服务器，不进行数据存储。前条所述的本地数据始终保存在您本人的设备上，我们不具备访问能力。

（二）保存期限

本地数据的保存期限由您自行决定。在您不主动删除的情况下，本地数据会一直保留在您的设备上，以便您随时继续游戏。

（三）删除方式

您可以通过以下任一方式删除全部本地数据：

1. 在游戏开始界面或会话菜单中使用“重置进度”功能；

2. 直接删除上述应用数据目录下的 FindDaisy2.Neutralino 文件夹；

3. 卸载本游戏后手动删除该文件夹。

（四）数据出境

本游戏不进行任何数据传输，不存在个人信息出境的情形。

三、我们如何使用 Cookies 和同类技术

本游戏不使用 Cookies，不使用网页信标、像素标签、设备指纹或任何形式的统计埋点，不生成广告标识符，不进行跨应用或跨网站的追踪。

本游戏在桌面版运行时不依赖浏览器存储。若您以浏览器方式打开开发版本，仅会使用浏览器本地存储保存前述“游戏进度”与“使用偏好”两类数据，该数据同样只存在于您的本机，不会传输至任何服务器。

四、我们如何共享、转让、公开披露您的个人信息

由于本游戏不收集个人信息，我们不存在向第三方共享、转让或公开披露您个人信息的情形。

我们不会出售您的任何信息。我们不会委托任何第三方处理您的个人信息。

五、第三方产品或服务如何获得您的个人信息

本游戏未接入任何第三方软件开发工具包，未接入广告投放平台、数据统计分析平台、支付服务、推送服务或社交分享服务。

本游戏的运行依赖 Windows 系统提供的 Microsoft Edge WebView2 运行时组件。该组件属于操作系统环境的一部分，由您的系统提供并受其自身条款约束，我们不通过该组件获取您的任何个人信息。

若您通过 TapTap 客户端下载、安装或启动本游戏，TapTap 平台可能依据其自身的隐私政策处理与您相关的信息，例如账号信息与下载记录。该部分处理行为由 TapTap 平台独立负责，不属于本政策的范围，建议您同时阅读 TapTap 平台的隐私政策。

六、我们如何保护您的个人信息

由于本游戏不收集、不上传个人信息，不存在个人信息在传输和服务器存储环节泄露的风险。

本游戏写入本机的进度数据与偏好数据受您操作系统账户权限的保护，其他用户账户无法直接读取。同时，本游戏在运行环境中关闭了对外网络连接能力，并禁用了摄像头、麦克风、定位、屏幕捕获、剪贴板读写、USB 设备等接口，以降低信息被读取的可能。

请您理解，上述本地数据的安全性同时取决于您对计算机本身的保管。若您的设备被他人直接使用或系统账户权限被他人获取，本地文件可能被他人读取，此种情形不属于我们的责任范围。

七、您如何管理您的个人信息

（一）查阅与更正

本游戏保存的本地数据量很小且为游戏运行所必需。您可以通过游戏内的继续游戏功能查看当前的进度状态；如需更正，可通过重置进度后重新开始实现。

（二）删除

您可以随时使用游戏内的“重置进度”功能，或按本政策第二条载明的方式删除本地数据目录，删除后不可恢复。

（三）撤回授权

本游戏的运行不以您授予任何系统权限或个人信息授权为前提，因此无需撤回授权即可完整游玩。

（四）注销账号

本游戏不设账号体系，不存在账号注销的情形。

（五）响应您的请求

如您对本政策或本地数据有任何疑问，可通过本政策第十条载明的方式与我们联系，我们将在十五个工作日内回复。

八、我们如何处理未成年人的个人信息

本游戏不收集任何用户的个人信息，因此不存在针对未成年人个人信息的收集、使用、存储或共享行为。

本游戏为单机运行的叙事探索游戏，内容不含暴力血腥、赌博、色情或其他不适宜未成年人的要素。我们建议未满十八周岁的用户在监护人的陪同下阅读本政策并游玩，监护人可协助未成年人管理本机的游戏进度数据。

如监护人发现未成年人在使用本游戏过程中产生了需要处理的问题，可通过本政策第十条载明的方式与我们联系。

九、本隐私政策如何更新

我们可能会因功能调整或法规变化而更新本政策。更新后的政策将在本页面公布，并同步修改页面顶部的更新日期。

若更新涉及您权利的重大变化，我们会在游戏开始界面以显著方式提示。未经您重新确认，我们不会削减您依据本政策所应享有的权利。

历史版本我们将予以留存，供您查阅。
